# 習慣小屋 Habit House

像素風立體小屋的習慣養成遊戲。每新增一個習慣，就有一位小居民搬進小屋；你每天打卡，他們就會自己生活：吃飯、睡覺、洗澡、玩樂，也會交朋友、吵架、談戀愛。

單一 `index.html`，不需要安裝、不需要伺服器，打開就能玩，也可以放著掛機。

## 玩法

- 新增習慣 → 一位居民入住，可以自訂外觀、三種個性（衝突的個性不能同時選）
- 每天打卡 → 居民保持活力；連續打卡每 5 天精進一級，外觀會有變化
- 點居民 → 看立繪、聊天、下指令、送禮物，他們會依個性與心情回應
- 商城與佈置模式 → 用金幣買家具、公共設備與裝飾
- 居民之間會有好感事件、不合事件與突發狀況（吵架、發燒、停電…），也會偷偷告訴你秘密
- 最多 8 層樓、40 位居民

## 掛機

右側「掛機與存檔」面板：

- **離開時也繼續生活**：切到別的分頁、鎖螢幕或關掉網頁，回來時會自動補算（最多 24 小時），並顯示離線報告
- **時間流速**：預設現實 2 小時＝小屋 1 天，可切換快／適中／慢／真實；小屋有年、月、週、星期
- **工作與存款**：居民依職業在不同日子、時段出門上班賺錢，會自己逛街買家具、送禮物、請大家吃飯
- **信箱**：居民會留言或問你問題（告白、求婚、換工作、婚禮、同居、幫寶寶取名…），你的選擇會改變他們的人生
- **週日派對**：每週輪換主題，3 人以上報名才會舉辦
- **省電模式**：降低畫面更新率與解析度
- **保持螢幕不休眠**：使用瀏覽器的 Screen Wake Lock（需瀏覽器支援）
- 分頁標題會顯示還有幾個習慣沒打卡，例如 `(3) 習慣小屋`
- 掛機期間不會觸發緊急狀況，不會因為你不在而受罰

手機可以「加到主畫面」，以全螢幕 App 的方式開啟。

## 存檔

進度存在**這個瀏覽器的 localStorage**，每 30 秒自動存一次。換裝置、換瀏覽器或清除瀏覽資料前，請先用「匯出存檔」下載 JSON，之後用「匯入存檔」還原。

## 部署

這是純靜態網站。用 GitHub Pages：Settings → Pages → Source 選 `main` 分支、根目錄 `/`。

本機也可以直接雙擊 `index.html` 開啟。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 整個遊戲（程式、樣式、立繪都在裡面） |
| `manifest.webmanifest`、`icons/` | 讓網頁可以加到手機主畫面 |

## 備註

- 居民立繪由 Canva AI 生成，遊戲在執行時依每位居民的髮色、眼睛、衣服與膚色重新上色。
- 字型使用 Google Fonts 的 DotGothic16；離線時會改用系統字型。
